# Problem Definition

## Conflict-avoiding codes

For `n >= 1`, write `Z_n` for integers modulo `n`. For a weight-`w` subset `x` of `Z_n`, define

`Delta(x) = {a-b mod n : a,b in x, a != b}`.

A conflict-avoiding code of length `n` and weight `w` is a collection `C` of weight-`w` subsets such that `Delta(x)` and `Delta(y)` are disjoint for distinct codewords `x,y` in `C`. An optimal CAC has maximum possible cardinality.

In the communications model, a codeword is a periodic binary transmission schedule. Difference-set disjointness gives a deterministic collision-avoidance guarantee under cyclic offsets in a multiple-access channel without feedback.

## Phase 1 target: Conjecture B

Let `p` be an odd prime and let `H = <-1,2>` be the subgroup generated by `-1` and `2` in `F_p^*`. Put `ell = [F_p^*:H]`.

When `ell >= 3`, the quotient `F_p^*/H` is cyclic. Conjecture B asks whether there always exists a generator coset `tH` and elements

- `b in tH`,
- `c in t^2H`,
- `1+b=c mod p`.

The cited literature explains how such a witness yields the nonequidifference component needed by a known optimal-code construction. The first project milestone is not the whole odd-length classification; it is a fully attributed, reproduced, and attack-tested formulation of this prime-length target.

## Commercial relevance boundary

CAC size corresponds to the number of potential users supported by the modeled deterministic access system. Better constructions can improve supported-user capacity for fixed schedule length and transmission weight in settings where feedback is absent or undesirable.

Project Kronos does not yet establish suitability for a deployed wireless, IoT, RFID, satellite, or industrial system. Translation from the mathematical model to any product requires engineering assumptions, protocol design, simulation, and domain validation.
